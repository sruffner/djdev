# Changelog

## v0.2.0 (06/21/2022)

- Eliminated use of the pickle module in serializing and deserializing API responses.
- A number of significant changes were made to the data containers exposed in the sglportalapi package, primarily to 
implement serialization of the containers without depending on the pickle module.

## v0.1.0 (05/11/2022)

- First release of `sglportalapi`
